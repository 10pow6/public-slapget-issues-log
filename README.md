# Slapget — Public Issue Tracker

Welcome! This is the **public bug & feedback tracker** for [Slapget](https://slapget.com) — real satellite ground, sliced into 10 × 10 m parcels and rendered as a retro JRPG overworld. Claim parcels on the web map, then walk, survey, gather, and build on them in the desktop engine.

This repository contains **no source code**. It exists so players can report bugs, request features, and track what we're working on — all in the open.

---

## 🐛 Found a bug? Have an idea?

[**→ Open a new issue**](https://github.com/10pow6/public-slapget-issues-log/issues/new/choose)

Pick the right template and fill in as much as you can:

| Template | Use it when… |
|----------|--------------|
| 🐛 **Bug Report** | The map, a claim, your properties, the wallet connection, or the desktop engine isn't working right. |
| ✨ **Feature Request** | You have an idea for a new mechanic, resource, region, or quality‑of‑life improvement. |

Before opening one, please [**search existing issues**](https://github.com/10pow6/public-slapget-issues-log/issues?q=is%3Aissue) — if your bug or idea already exists, add a 👍 or a comment instead of opening a duplicate. It helps us prioritize.

## 🔒 Security issues

**Do not** open a public issue for security vulnerabilities. [**Report it privately →**](https://github.com/10pow6/public-slapget-issues-log/security/advisories/new) (see [**SECURITY.md**](SECURITY.md) for what to include and what's out of scope).

> ⚠️ Reports involving **TP6 payments**, the wallet connection, claiming the same parcels twice, getting resources or land without paying, or seeing hidden deposits or other players' private data are **security‑sensitive**. Report those privately, not here.

## 💬 Want to chat instead?

Join the community on **Discord** (linked from the [Slapget site](https://slapget.com)) for live discussion, help, and announcements. GitHub issues are best for things we need to track and fix; Discord is best for questions and conversation.

New to Slapget? The in‑site help pages ([Getting Started](https://slapget.com/docs/start), [Pricing](https://slapget.com/docs/pricing), [Resources](https://slapget.com/docs/resources), [Engine](https://slapget.com/docs/engine)) answer most "how does this work?" questions.

## How we handle issues

- We triage new issues and apply labels (e.g. `bug`, `enhancement`, `needs-info`, `confirmed`, `wontfix`).
- If we need more detail we'll add `needs-info` and comment — please reply, or we may close the issue after a while.
- Fixed issues are closed with a note. Shipped features are closed when they go live.
- This is the canonical place to see **what's reported and what's planned**.

## Tips for a great report

1. **One issue per report.** Separate bugs into separate issues.
2. **Be specific.** "Claim panel shows a different price than I was charged" beats "claiming is broken."
3. **Include steps** to reproduce, what you expected, and what actually happened.
4. **Say where it happened**: the web site or the desktop engine. For the engine, include its version.
5. **Name the place.** Include the region, plus the property permalink or parcel coordinates if you have them.
6. **Add screenshots or a short clip** when the bug is visual, but **redact anything private** (wallet details, account email).
